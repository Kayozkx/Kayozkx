👋 Sobre mim

Estou construindo uma base sólida em redes de computadores e infraestrutura, com Linux (Ubuntu) como sistema principal no meu dia a dia — não só como escolha, mas como ferramenta de aprendizado constante: cada configuração, erro e ajuste vira uma oportunidade de entender o sistema mais a fundo.

Meu jeito de aprender é prático: prefiro testar, quebrar, consertar e documentar o processo, a decorar teoria sem aplicação. É assim que o projeto fixado abaixo nasceu — de um problema real que eu mesmo enfrentei.

Ainda estou definindo se meu caminho vai mais para infraestrutura de redes ou para cybersegurança — e tô tranquilo com isso, porque sei que a base é a mesma, e continuo evoluindo nas duas direções enquanto decido.

🔧 Scroll Lock RGB Fix — serviço em Python para corrigir a iluminação RGB de teclados gamer genéricos em sistemas GNOME/Wayland, onde o driver depende do estado do LED de Scroll Lock (que o Wayland deixou de sincronizar).

O que o projeto mostra na prática:


🔍 Diagnóstico estruturado de um problema real de hardware/kernel (22 comandos documentados até isolar a causa)
⚙️ Serviço rodando em background via systemd, com início automático no boot
🐍 Monitoramento de eventos de teclado em tempo real com a biblioteca evdev
📄 Documentação técnica completa incluída no repositório, explicando cada decisão
